# <user>/tinyops-tiny-aya-sft  (SFT stage, draft)

LoRA adapter for **CohereLabs/tiny-aya-global** that makes the model call Kubernetes incident-response
tools correctly and ignore instructions hidden in tool output. Trained in a **simulated** cluster
(KubeSim) for research; not validated on real clusters.

## Training
- Method: supervised fine-tuning, assistant-only loss, LoRA r=16 alpha=32
  dropout=0.05 on all linear layers; lr 0.0001, 2 epochs, effective
  batch 16, max length 4096, seed 1234.
- Data: _not evaluated yet_. Generated by `python -m tinyops.scenarios.build_dataset` (seed 1234); the test splits were never used.
- Selected checkpoint: _not evaluated yet_.

English only; one model size.
